平均海面基準の潮位モデル（m）

これはOpen-Meteoの海洋潮位モデルによる推算です。満潮・干潮の表示は1時間値から推定した局所的な山・谷であり、公式の満干潮時刻・潮高ではありません。海図基準面の潮高とも異なります。

海しる公式潮汐推算 API

サーバー側でAPIキーと接続先を設定すると、選択地点の公式潮汐推算データを自動取得します。未設定時は「未接続」と表示し、既存のOpen-Meteoモデルと混同しません。

未確認

公式APIの潮位基準面・単位・適用地点は接続先仕様に従います。モデル潮位と重ね合わせて比較しないでください。

自動取得・潮汐データ

CSV操作は不要です。ページを開くと、選択した4地点の海洋潮位モデルを自動取得し、1時間ごとの潮位グラフに表示します。上の「潮位モデル・1時間別グラフ」が自動更新対象です。

航海安全上の注意
波高・うねり・風速は格子点の予報値で、港内や岬の局所的な海況を表す実測値ではありません。「潮位モデル」は平均海面基準の広域推算であり、港ごとの公式潮汐表・海図基準面の潮位とは異なります。潮位モデルを航行判断や水深計算に使わないでください。出航前に気象庁の海上警報、海上保安庁の情報、公式潮汐表を確認してください。出航可否の自動判定は行いません。
